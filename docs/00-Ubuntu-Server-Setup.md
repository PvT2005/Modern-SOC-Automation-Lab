# Thiết lập Ubuntu Server 
Ubuntu Server được tinh chỉnh để chạy và cài đặt Wazuh Manager và TheHive .

## 1. Cấu hình Máy ảo 
- OS: Ubuntu Server 22.04 LTS .

- CPU: 3 Cores.

- RAM: 10GB

## 2. Cấu hình Mạng nội bộ 
- Network Adapter: Chế độ Host-Only 
- Địa chỉ IP : 192.168.56.10
- Địa chỉ IP Win10: 192.168.56.20
- Subnet: 255.255.255.0 (/24)
